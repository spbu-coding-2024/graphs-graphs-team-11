## О проекте

**GraphVisualize** — это десктопное приложение с графическим интерфейсом на Kotlin + Jetpack Compose, позволяющее:

1. Визуализировать произвольные неориентированные и ориентированные и взвешенные графы.
2. Применять современные и классические алгоритмы анализа.
3. Сохранять/загружать графы в файлы, SQLite и Neo4j.

---

## Стек технологий

- **Язык:** Kotlin
- **UI:** Jetpack Compose for Desktop
- **СУБД:** SQLite, Neo4j
- **Сборка:** Gradle (Kotlin DSL)
- **Тестирование:** JUnit

---

## Возможности приложения

- **Визуализация графа**
    - Размещение вершин на плоскости по алгоритму ForceAtlas2
    - Интерактивное перемещение, масштабирование и перетаскивание
- **Анализ графа**
    - Выделение ключевых вершин
    - Поиск сообществ
    - Классические алгоритмы: компоненты сильной связности, мосты, поиск циклов
    - Взвешенные алгоритмы: минимальное остовное дерево (Kruskal), кратчайший путь
- **Сохранение и загрузка**
    - Чтение/запись в CSV
    - SQLite
    - Neo4j

## Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/spbu-coding-2024/graphs-graphs-team-11.git
   cd graphs-graphs-2024/graphs-graphs-team-11
   ```
2. Сборка и запуск:
   ```bash
   ./gradlew run
   ```
3. Скомпилированный JAR будет в `composeApp/build/libs/`.

---

## Использование

1. **Загрузка графа** через меню **File → Open** (поддерживаются CSV).
2. **Анализ**: откройте вкладку **Алгоритмы** и выберите нужный алгоритм.
3. **Работа с базами**: можно загрузить или сохранить граф (SQLite/Neo4j).

---

## Реализованные алгоритмы

### Современные алгоритмы (≥2006)
| Алгоритм                                | Описание                     |
|-----------------------------------------|------------------------------|
| ForceAtlas2                             | Раскладка графа на плоскости |
| Collective Influence (ключевые вершины) | Оценка важности вершин       |
| DLPA (поиск сообществ)                  | Распространение меток        |

### Классические алгоритмы
- **Сильная связность** (Kosaraju)
- **Поиск мостов** (DFS-базированный)
- **Поиск циклов** (DFS)

### Взвешенные алгоритмы
- **Минимальное остовное дерево** ()
- **Кратчайший путь** (Dijkstra, Bellman–Ford)
