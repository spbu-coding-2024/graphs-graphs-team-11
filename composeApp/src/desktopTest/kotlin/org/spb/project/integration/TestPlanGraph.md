# План интеграционных тестов

## 1. addCircleIncreasesCircleNodesListByOne
- **Назначение:** Проверить, что при вызове `addCircle` в список `circleNodes` добавляется ровно один новый узел.
- **Предусловия:** Новый экземпляр `CanvasPresenter` с пустым графом (вызов `loadGraph` с новым `graphId`).
- **Шаги теста:**
    1. Сохранить текущее количество узлов (`presenter.circleNodes.size`).
    2. Вызвать `presenter.addCircle(color)` с произвольным цветом.
    3. Снова измерить размер списка `circleNodes`.
- **Ожидаемый результат:** Размер списка увеличился на 1.
- **Обоснование:** Базовая функциональность — добавление узла — должна работать корректно.

---

## 2. selectNodeAndPaintSelectedNodeChangesOnlyThatNodeColor
- **Назначение:** Убедиться, что при выделении узла и вызове `paintSelectedNode` изменяется цвет только этого узла, а остальные остаются без изменений.
- **Предусловия:** Два различных узла добавлены через `addCircle`, у каждого свой начальный цвет.
- **Шаги теста:**
    1. Добавить два узла.
    2. Вызвать `presenter.selectNode(index)` для второго узла.
    3. Вызвать `presenter.paintSelectedNode(newColor)`.
    4. Проверить, что у выделенного узла цвет равен `newColor`, а у остальных узлов цвета прежние.
- **Ожидаемый результат:** Изменился цвет только выбранного узла.
- **Обоснование:** Проверка корректности «выделить и изменить» — важного пользовательского сценария.

---

## 3. paintAllSetsSameColorForEveryNode
- **Назначение:** Убедиться, что метод `paintAll` устанавливает переданный цвет всем узлам графа.
- **Предусловия:** В `presenter.circleNodes` присутствуют минимум три узла с разными цветами.
- **Шаги теста:**
    1. Добавить три узла с разными цветами через `addCircle`.
    2. Вызвать `presenter.paintAll(uniformColor)`.
    3. Проверить, что у каждого узла цвет равен `uniformColor`.
- **Ожидаемый результат:** Все узлы получают одинаковый цвет.
- **Обоснование:** Тестируется массовое изменение свойств узлов — частая операция при работе с графами.

---

## 4. deleteSelectedNodeRemovesOnlyTheSelectedNode
- **Назначение:** Проверить, что при удалении выбранного узла методом `deleteSelectedNode` удаляется только он, и список оставшихся узлов корректно смещается.
- **Предусловия:** В графе не менее трёх узлов.
- **Шаги теста:**
    1. Добавить три узла.
    2. Запомнить список цветов узлов в порядке добавления.
    3. Вызвать `selectNode(1)` для среднего узла.
    4. Вызвать `deleteSelectedNode()`.
    5. Сравнить новый список цветов с ожидаемым (без второго элемента).
- **Ожидаемый результат:** Размер списка уменьшился на 1; оставшиеся цвета соответствуют первым и третьим первоначальным узлам.
- **Обоснование:** Проверяется целостность списка узлов после удаления, критично для корректного поведения UI.

---

## 5. saveAndLoadGraphRestoresState
- **Назначение:** Убедиться, что при сохранении графа в базу и последующей загрузке состояние узлов (цвета и количество) восстанавливается полностью.
- **Предусловия:** Пустой граф, загруженный в `presenter` через `loadGraph(newId)`.
- **Шаги теста:**
    1. Добавить два узла и вызвать `paintAll` для установки единого цвета.
    2. Сохранить список текущих цветов и количество узлов.
    3. Вызвать `presenter.saveGraph(testGraphId)`.
    4. Создать новый экземпляр `CanvasPresenter` и вызвать `loadGraph(testGraphId)`.
    5. Сравнить количество и цвета узлов в новом экземпляре с ранее сохранёнными.
- **Ожидаемый результат:** После загрузки графа количество узлов и их цвета совпадают с сохранёнными.
- **Обоснование:** Проверяется полноценное сквозное сохранение и загрузка данных — ключевой аспект надёжности приложения.

## Общая картина
Эти пять сценариев обеспечивают покрытие основных операций пользователя:
- Добавление узлов
- Выделение и изменение цвета одного узла
- Массовое изменение цвета всех узлов
- Удаление выбранного узла
- Сохранение и восстановление состояния графа

Тесты затрагивают Presenter и его взаимодействие с базой данных, что соответствует определению интеграционного тестирования: проверка связки нескольких компонентов вместе.
